# 解析即装载播放器，但不出声

用户拍板的是时机：解析成功就装载播放器，而不是等点下载那一刻才装载。表现由我替他定了另一半——装载后 `playing=false`，要出声仍需按播放键。理由是这类终端多在办公室或耳机未就绪的情况下用，解析完就放歌会吓人一跳，而且直链取流会白跑一路连接。

放弃的方案：点下载那一刻才装载（把下载与试听绑成一件事，但用户明确说试听是顺带的）；解析即自动播放（试听最快，却与「下载优先」的定位相反）。

配套事实，值得记下来否则后人还会再踩：本地 vendor 的 APlayer `List.add` 只接受一个参数，`add(audios, true)` 的第二个参数被静默忽略——起播必须显式 `ap.play()`，不能指望构造参数。原先「点行内播放却不出声」的缺陷就是这么来的。
